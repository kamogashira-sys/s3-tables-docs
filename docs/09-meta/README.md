# メタ情報

ドキュメントの変更履歴やメタ情報を管理するフォルダです。

## このフォルダの内容

| ドキュメント | 説明 |
|------------|------|
| [changelog.md](changelog.md) | ドキュメントの変更履歴 |

## 対象読者

- ドキュメント管理者
- コントリビューター
- すべてのユーザー（変更履歴の確認）

## 変更履歴の活用

### 最新の変更を確認
[changelog.md](changelog.md)で最新の更新内容を確認できます。

### バージョン管理
ドキュメントの各バージョンでの変更点を追跡できます。

### 更新通知
重要な変更や新機能の追加を把握できます。

## ドキュメント貢献

ドキュメントへの貢献を歓迎します。変更を行った場合は、必ず[changelog.md](changelog.md)を更新してください。

### 変更履歴の記載方法

```markdown
## [バージョン] - YYYY-MM-DD

### 追加
- 新しいドキュメントや機能の追加

### 変更
- 既存ドキュメントの更新

### 修正
- 誤字脱字やリンク切れの修正

### 削除
- 廃止されたドキュメントや情報の削除
```
