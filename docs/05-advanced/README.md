## アーキテクチャパターン

### アクティブ-アクティブ構成
複数リージョンで同時にデータを処理し、高可用性を実現

### アクティブ-スタンバイ構成
プライマリリージョンで運用し、セカンダリリージョンをDR用に維持

### ハイブリッド移行
既存データレイクとS3 Tablesを並行運用しながら段階的に移行
